# Архив проекта (Historical Archive)

Данная директория содержит материалы, черновики, промежуточные аудиты и логи ранних этапов проектирования **Sample Browser** (октябрь – начало ноября 2026 г.).

> [!CAUTION]
> **Материалы в этой папке не являются актуальными спецификациями продукта!**
> На встрече 6–7 ноября 2026 года команда провела архитектурный пивот, зафиксированный в [`meetings/2026-11-07_pivot_meeting_notes.md`](../meetings/2026-11-07_pivot_meeting_notes.md).
> Для работы используйте актуальные документы в папке [`docs/`](../docs/).

---

## Структура архива

### 1. `early_drafts/` (Ранние черновики Midterm 1, октябрь 2026)
Черновики формулировки проблемы, анализа предметной области и проектного предложения до пивота:
* `better_spotify_domain_analysis.md` — ранний анализ домена (с предпосылкой создания альтернативного плеера для Spotify и описанием ограничений Spotify Web API).
* `bogdan_domain_analysis.md` — авторский черновик Богдана Глэвана по целям слушателей и продюсеров.
* `ai_remade_domain_analysis.md` — литературная обработка черновика Богдана с первыми ссылками на Tracklib и IFPI.
* `early_problem_statement_pd_ps.md` — первая формулировка проблемы (содержала противоречие *Vocabulary Gap*).
* `early_solution_description.md` — раннее описание решения с неструктурированными текстовыми тегами и фильтром нецензурных слов.
* `early_swot.md` — первоначальный SWOT-анализ.
* `early_interview_questions_draft.md` — черновик опросника Андрея Симона до переработки в 10-вопросный протокол *The Mom Test*.
* `early_proposal_sample_browser.docx` — выгрузка ранней версии проектного предложения в формате Word.

### 2. `audits/` (Аудиторские отчёты этапа выравнивания)
* `Sample_Browser_Audit_Report_RU.md` / `Sample_Browser_Audit_Report_EN.md` — аналитические аудиты, выявившие противоречия между литературой (*Vocabulary Gap*), правилами YouTube API и гипотезами валидации. Эти дефициты легли в основу пивота 6–7 ноября.

### 3. `milestone0_ideation/` (Этап генерации первоначальных идей)
* `1.milanote_map.pdf` — экспорт интеллект-карты Milanote с мозговым штурмом команды.
* `1.team_work_on_mila_notes.md` — текстовый лог работы над картой Milanote.
* `2.first_proposal_attempt.md` — самая первая попытка оформления проектного предложения.
* `3.correcting_mistakes_domain_analysis_and_new_ideas.md` — промежуточная фиксация замечаний и новых идей.
* `4.four_final_problem_statements.txt` — драфты вариантов Problem Statement.

### 4. `raw_logs/` (Сырые логи коммуникации)
* `telegram_chat_messages.txt` — выгрузка сообщений из рабочего Telegram-чата команды Team 16.
